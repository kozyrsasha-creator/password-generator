# GetPassnow - Password Generator

Обновлённая версия генератора паролей с современным дизайном и тёмной темой.

## 🎨 Что нового

- **Современный дизайн** с градиентами и glassmorphism эффектами
- **Тёмная тема** с переключателем (сохраняется в localStorage)
- **Улучшенная типографика** и иконки Bootstrap Icons
- **Плавные анимации** и hover-эффекты
- **Адаптивный дизайн** для всех устройств
- **Улучшенная читаемость** в обеих темах

## 🚀 Установка на Vercel

### Способ 1: Через Vercel CLI

```bash
# Установите Vercel CLI (если не установлен)
npm install -g vercel

# Войдите в аккаунт
vercel login

# Разверните проект
vercel --prod
```

### Способ 2: Через GitHub

1. Загрузите файлы в ваш GitHub репозиторий:
```bash
git add .
git commit -m "Update design with dark theme"
git push origin main
```

2. Vercel автоматически задеплоит изменения (если настроена интеграция)

### Способ 3: Через веб-интерфейс Vercel

1. Зайдите на [vercel.com](https://vercel.com)
2. Откройте проект **getpassnow**
3. Загрузите файлы через интерфейс

## ✨ Основные функции

- **100% клиентская генерация** - всё работает локально
- **Криптографически безопасно** - используется Web Crypto API
- **Настраиваемая длина** - от 8 до 64 символов
- **Гибкие настройки** - выбор типов символов
- **Дополнительные опции**:
  - Без повторяющихся символов
  - Исключение похожих символов (O, 0, l, 1, I)
  - Исключение скобок
- **Индикатор надёжности** с расчётом энтропии
- **Расчёт времени взлома**
- **Мгновенное копирование** в буфер обмена

## 🎨 Темы

Переключатель тем находится в правом верхнем углу навигации:
- ☀️ Светлая тема (по умолчанию)
- 🌙 Тёмная тема

Выбранная тема сохраняется в localStorage.

## 📱 Адаптивность

Сайт полностью адаптирован для:
- Десктопов (1200px+)
- Планшетов (768px - 1199px)
- Мобильных устройств (< 768px)

## 🔒 Безопасность

- Генерация происходит полностью на стороне клиента
- Никакие данные не отправляются на сервер
- Используется `crypto.getRandomValues()` для криптографической случайности
- Нет сбора аналитики или трекинга
